# ELCEO UI Design Foundation

This directory is the durable visual, motion, responsive, performance, editorial, legal-UX, asset-planning, and migration authority for the production frontend.

The approved landing-page mockup at `references/approved-landing-reference.webp` is the visual reference. The documents in this directory explain how that reference and the wider ELCEO product language are to be implemented without generic substitution or unauthorized redesign.

## Authorities

- `ELCEO_UI_CONSTITUTION.md` — product identity, authority hierarchy, no-generic-substitution rules, dashboard protection, backend boundary.
- `ELCEO_VISUAL_LANGUAGE.md` — color roles, surfaces, spacing categories, typography, iconography, imagery, editorial composition.
- `ELCEO_LANDING_SCENE_CONTRACT.md` — seven-scene landing narrative, approved composition behavior, globe/continent system, card mosaic, CTA.
- `ELCEO_MOTION_GRAMMAR.md` — GSAP/Motion/CSS/Three ownership, motif handoff, spatial transitions, timing and accessibility.
- `ELCEO_RESPONSIVE_RULES.md` — authored mobile behavior, essential/adaptive/desktop-enhancement classes, touch/media rules.
- `ELCEO_PERFORMANCE_BUDGET.md` — Web Vitals, memory/GPU acceptance, rendering/asset budgets and 3D/video constraints.
- `ELCEO_EDITORIAL_STANDARD.md` — voice, concrete trader language, restricted financial claims, CTA language.
- `ELCEO_LEGAL_UX_MATRIX.md` — Terms/risk/privacy/cookies/signup/age-attestation/billing/admin trust requirements.
- `ELCEO_ASSET_REGISTER.md` — asset classification, provenance, initial production register, split/fallback requirements.
- `NEXTJS_MIGRATION_PLAN.md` — Vite-to-Next.js migration constraints and sequencing, with dashboard parity protection.
- `WORK_START_PROTOCOL.md` — mandatory GPT Work/Codex startup audit and stop conditions.
